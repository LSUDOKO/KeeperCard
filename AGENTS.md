# KeeperCard

Spending cards for AI agents. KeeperCard decides what an agent may spend; KeeperHub moves the money.

Package manager: bun.

## Commands

- dev: `bun dev`
- test: `bun test`
- typecheck: `bun typecheck`

## Layout

- `contracts/`
- `docs/`
- `harness-privy/`
- `packages/`
- `probes/`
- `video/`

## Rules

- Run `bun test` before you say a change is done.
- Never commit secrets or `.env` files.
